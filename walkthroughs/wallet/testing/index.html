Testing

How the wallet and the ledger are tested: each package as a unit, on fakes and the humustest Host; the Store against PostgreSQL; the key set served by the tests’ own handler; two ledger replicas behind a dialer of the tests’ own; the shared cases, their Target, Parallel and Alone, run inside synctest, against PostgreSQL and on kind; and the failure injection cases.

The ledger’s unit tests

The ledger’s server takes a Store, so its tests give it a fake one, in memory, that fails when the test says so:

func (f *fakeStore) Account(_ context.Context, id string) (store.Account, error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	f.reads++
	if f.err != nil {
		return store.Account{}, fmt.Errorf("reading account %s: %w", id, f.err)
	}
	a, ok := f.accounts[id]
	if !ok {
		return store.Account{}, fmt.Errorf("reading account %s: %w", id, store.ErrNotFound)
	}
	return a, nil
}

The two ledger replicas

A rollout replaces one replica at a time, so the shared cases run two ledger Apps. Their dialer does what a ClusterIP Service does: it sends the ledger’s address to one of the replicas still in its endpoints, and refuses the dial when there is none:

func (n *network) Dial(ctx context.Context, network, address string) (net.Conn, error) {
	n.mu.Lock()
	s := n.services[address]
	n.mu.Unlock()
	if s == nil {
		return n.base(ctx, network, address)
	}
	endpoint, ok := s.pick()
	if !ok {
		return nil, &net.OpError{Op: "dial", Net: network, Err: os.NewSyscallError("connect", syscall.ECONNREFUSED)}
	}
	return n.base(ctx, network, endpoint)
}

A rollout takes each replica out of the endpoints, stops it with SIGTERM, starts it again, and puts it back once it is ready:

func (s *service) rollout(ctx context.Context) error {
	s.mu.Lock()
	replicas := slices.Clone(s.replicas)
	s.mu.Unlock()
	for _, r := range replicas {
		s.remove(r)
		if err := r.stop(ctx); err != nil {
			return err
		}
		r.run()
		if err := r.ready(ctx); err != nil {
			return err
		}
		s.add(r)
	}
	return nil
}

The shared cases

The cases are the package cases, which imports neither App nor humustest, so the compiler keeps them black-box. It imports walletpb and ledgerpb, as any client would. A Target says how to reach both services:

type Target struct {
	Wallet grpc.ClientConnInterface

	Ledger                   grpc.ClientConnInterface
	LedgerWithoutCertificate grpc.ClientConnInterface

	Token func(subject string, scopes ...string) (string, error)

	RolloutWallet func(ctx context.Context) error
	RolloutLedger func(ctx context.Context) error

	ScenarioKey string
	TrustScope  string
	Timeout     time.Duration
}
FieldWhat it is
Walleta connection to the wallet that trusts its certificate
Ledgera connection to the ledger with the cases’ client certificate, to open and fund accounts
LedgerWithoutCertificatea connection to the ledger with no client certificate
Tokensigns a token for a subject, with scopes, that the wallet accepts
RolloutWallet, RolloutLedgerroll each service out, one replica at a time, and return once it is done
ScenarioKeythe baggage member the services decode a scenario from
TrustScopethe scope a token needs for the wallet to trust its scenario
Timeouthow long a case may take

func (s *memoryStore) inject(ctx context.Context) error {
	f := s.faults.Eval(ctx, ledgerPoint)
	if err := f.Wait(ctx); err != nil {
		return fmt.Errorf("%w: %w", store.ErrUnavailable, &fault.InjectedError{Point: ledgerPoint, Err: err})

The failure injection cases

A case rehearses a failure by sending a scenario in the call’s baggage metadata, with a token whose scopes hold the trust scope:

func newRehearser(ctx context.Context, t testing.TB, target Target, amountCents int64) holder {
	t.Helper()
	require.NotEmpty(t, target.TrustScope, "Target.TrustScope")
	return newFunded(ctx, t, target, amountCents).withScopes(t, target, scopeRead, scopeWrite, target.TrustScope)
}

func (h holder) rehearsing(t testing.TB, rules ...fit.Rule) holder {
	t.Helper()
	require.NotEmpty(t, h.target.ScenarioKey, "Target.ScenarioKey")
	codec, err := jsonscenario.New(h.target.ScenarioKey)
	require.NoError(t, err, "Target.ScenarioKey")
	b, err := codec.Encode(baggage.Baggage{}, fit.Scenario{Rules: rules})
	require.NoError(t, err, "encoding the scenario")
	h.baggage = b.String()
	return h
}

func (h holder) with(ctx context.Context) context.Context {
	if h.token != "" {
		ctx = metadata.AppendToOutgoingContext(ctx, "authorization", "Bearer "+h.token)
	}
	if h.baggage != "" {
		ctx = metadata.AppendToOutgoingContext(ctx, "baggage", h.baggage)
	}
	return ctx
}
