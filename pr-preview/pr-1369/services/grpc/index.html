gRPC

Serving gRPC with the grpcserver package, from the grpc module.

A gRPC service registers its generated services on grpcserver’s Service and serves them over TLS, which Serving gRPC covers.

The wallet walkthrough builds a production-ready gRPC service step by step, and its code is example/grpc/wallet.

Serving gRPC

How to serve gRPC with the grpcserver package: an Init that sources grpcserver.Settings, registers generated services on the Service from NewService and returns it, the certificate it requires, what server options can change, how it ends streams and shuts down on grpcserver.Main’s defaults, how Kubernetes’ probes reach it, how grpcauth authenticates its RPCs, what it records, and how to test it with grpcservertest.
